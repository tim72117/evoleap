小森烘焙要用哪一種資料庫

依專案現況：網站放在 Cloud Run、預計每天 50 筆訂單、之後要會員登入與線上付款。

需求檔案SQLitePostgresFirestore
Cloud Run 重新啟動後資料還在✗✗ 檔案會不見✓✓
好幾個人同時下單不會蓋掉✗△✓✓
月底統計營收（加總、分組）✗✓✓△
訂單、會員、付款之間的關聯✗✓✓△
每月費用00約 NT$300 起小量免費
建議：Postgres（雲端代管的資料庫服務）
  • Cloud Run 的容器隨時會被換掉，SQLite 檔案留不住。
  • 訂單、會員、付款要互相對得上，關聯式資料庫最穩。
  • 本機開發先用 Docker 跑一份 Postgres，不碰正式資料。
