圖解 · 權限（IAM）

誰，拿哪一串鑰匙？

誰＋拿哪個角色＋對哪個專案

這一句就是一條 IAM 權限設定（IAM＝身分與存取管理）。

你你擁有者
🤖deployer服務帳號：給程式用的帳號
角色：Cloud Run 開發者
🔑 部署網站🔑 看網站設定
角色就是一串鑰匙：一組事先包好的權限
角色：擁有者（Owner）
🔑 部署🔑 刪資料庫🔑 看帳單🔑 改權限🔑 開任何服務🔑 …全部
鑰匙外洩：別人可以做任何事，包括開一堆機器挖礦
deployer 只拿這三串
🔑 Cloud Run 開發者🔑 映像檔寫入者🔑 服務帳號使用者
鑰匙外洩：最多只能部署網站，刪不了資料、看不到帳單

角色是一組包好的權限，像一串鑰匙。給人或程式權限，就是把某串鑰匙交給他。

服務帳號是給程式用的帳號，像一個機器人員工。自動部署、網站讀資料庫，都用它，不用你的帳號。

最省事的做法是給 Owner，什麼都能做。但鑰匙一旦外洩（例如不小心 push 到 GitHub），損失也是「什麼都可能」。

最小權限：只給完成工作需要的鑰匙，多一把都不給。出事時，損害就被關在小範圍裡。
