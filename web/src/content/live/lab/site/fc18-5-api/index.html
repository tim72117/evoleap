配額：每個服務的「上限」

保護你也保護雲端：一個錯誤的程式不會無限制地用下去。

Cloud Run：每個地區最多執行個體
3 ／ 100
Cloud SQL：每分鐘管理操作
15 ／ 180
Secret Manager：每分鐘讀取
40 ／ 90,000
地圖 API：每天請求（你自己設的上限）
920 ／ 1,000

配額用滿時，服務會回錯誤「超過配額」，而不是無限扣錢。有些配額可以自己調低，當作省錢的保險。

用量：最近 7 天的請求數

用量看的是「實際被呼叫了幾次」。週末客人多，請求也多。
