0 個：不收 CPU 的錢

無伺服器不是沒有伺服器，而是你不用管它。沒人來的時候，Cloud Run 把容器全關了，執行個體是 0。

第一位客人來了，Cloud Run 才打開一個容器招呼他。

客人變多，自動多開幾個；人少了再自動關掉。你只付有人用的時間。

冷啟動（從 0 開一個）
打開容器、啟動程式 2.4 秒
已經開著
0.1 秒

沒人一陣子後的第一位客人，要等容器從頭打開，叫冷啟動。想避免，可以設「最少保留 1 個」，代價是一直開著要付錢。

地區＝機房在哪裡。選離客人近的，網頁比較快。資料庫也要放在同一個地區。

記憶體不夠，容器會被強制重開；給太多，每秒的費用變高。先從小的開始，看記錄再調。
