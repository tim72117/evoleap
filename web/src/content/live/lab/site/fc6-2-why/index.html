.env密碼、API 金鑰

推上去等於把家裡鑰匙貼在公布欄。別人拿到金鑰，可以用你的帳號花錢。

改放：.env.example（只寫欄位名稱，不寫值）
data.db資料庫檔案

裡面是使用者的真實資料，而且一直在變。每次 commit 都多一份，越存越大，也可能外洩個資。

改用：建立資料表的程式（migration）＋假資料
dist/build 產物

是從原始碼「產生」出來的。存進去只會和原始碼打架：改了原始碼卻忘了重新 build，兩份就對不上。

需要時：npm run build 重新產生
node_modules/下載來的套件

動不動就上萬個檔案、幾百 MB，而且都是別人的程式。package.json 已經記下要哪些套件。

需要時：npm install 全部裝回來
