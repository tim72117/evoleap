MCP：幫 AI 接上外部工具的插座
每一個 MCP 伺服器，都是一個小程式，把一個外部服務的功能，變成 AI 可以呼叫的「工具」。
GitHub 伺服器
list_issues · get_issue · create_issue · merge_pull_request
讀寫權限看你給的權杖
資料庫伺服器
query · list_tables · describe_table
讀建議用唯讀帳號，AI 才改不到資料
瀏覽器伺服器
open · click · screenshot
操作會用你登入的狀態做事
設計稿伺服器
get_frame · get_styles

安裝前看三件事
① 誰做的？官方或可信任的來源
② 有哪些工具？能讀、能寫，還是能刪
③ 給它的權杖或帳號，權限是不是最小
