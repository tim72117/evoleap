終端機怎麼找到指令：PATH

PATH 是一張「要去哪些資料夾找指令」的清單。你打 npm，終端機就照順序一個一個資料夾找。

這個終端機視窗
% npm -v
command not found: npm
11.6.2

PATH 清單，依序找
  1. /opt/homebrew/bin沒有 npm
  2. /usr/local/bin沒有 npm
  3. /usr/bin沒有 npm
  4. /bin沒有 npm
  5. ~/.nvm/versions/node/v24/bin找到 npm！
