機密＝密碼、API 金鑰、權杖這些「被別人拿到就糟了」的東西。上面這三個地方都不適合放。

Secret Manager 是雲端的保險箱。每個機密一格，加密存放；網站執行時才去拿，程式碼和 git 裡都不會有。

每次換密碼，就存一個新版本。網站讀 latest（最新版），舊版本可以停用。換密碼不用改程式。

誰能打開保險箱，也用 IAM 管：只給網站的服務帳號「讀取」這個角色。
