比較 · 靜態網站平台

Cloudflare Pages、Vercel、Netlify

三個都能免費放靜態網站，差在額度、預覽網址和自動部署的細節。

Cloudflare PagesVercelNetlify
免費額度流量不限，每月建置次數有上限免費方案限個人、非商業用途每月有固定的用量額度
預覽網址每個分支都有每次 push 都有每個合併請求都有
自動部署連 GitHub 後 push 就上線連 GitHub 後 push 就上線連 GitHub 後 push 就上線
命令列工具wranglervercelnetlify

免費額度的數字常常調整，挑之前請 AI 幫你查官網最新的說明。做小店網站，三家的免費方案通常都夠用。

自動部署：第一次把平台和 GitHub 連起來，之後每次 push，平台自己抓新檔案、重新發布。

預覽網址：還沒正式上線的版本也有自己的網址，可以先傳給朋友看。看沒問題再合併回 main，正式網址才會換成新版。
