一筆紀錄＝一行

名稱：問的是誰（@ 代表網域本身）
類型：問的是哪一種資訊
值：答案

A：地址

這個名字的 IP 位址（舊式、四段數字）。瀏覽器拿到它，才知道網站在哪台主機。

🏠 → 185.199.108.153
AAAA：新式地址

一樣是 IP 位址，只是新版的 IPv6，比較長。有就一起設，沒有也能用。

CNAME：別名

「www 的地址，去問 xiaosen-dev.github.io」。像說「我住在他家」，對方搬家你不用改。

www ➜ xiaosen-dev.github.io ➜ IP
MX：收信的郵局

寄到 @xiaosen-bakery.com 的信，要送去哪台郵件主機。前面的數字是優先順序，越小越先。

✉️ → mx1.mail.example
TXT：貼在門上的告示

一段文字，給其他服務看的。常用來證明「這個網域是我的」，或聲明誰可以替你寄信（SPF）。

TTL：記住多久

別人查到答案後可以記住幾秒。3600 秒＝1 小時：一小時內不會再來問。改紀錄前把 TTL 調小，改完別人比較快看到。
