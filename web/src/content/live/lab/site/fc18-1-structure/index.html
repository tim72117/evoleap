帳號、帳單帳戶、專案

👤 Google 帳號　you@gmail.com你是誰：登入用
💳 帳單帳戶誰付錢：綁一張信用卡
📁 專案 xiaosen-bakery-prod正式網站用
Cloud RunCloud SQLSecret Manager
📁 專案 xiaosen-sandbox練習用，隨時可以刪
Cloud Run

帳號就是你登入用的 Google 帳號，代表「你是誰」。

帳單帳戶代表「誰付錢」，上面綁一張信用卡。用了多少，就從這裡扣。

專案像一個資料夾，裝一組相關的東西。正式網站和練習分成兩個專案，練習的刪掉也不影響正式的。

雲端服務（放網站、資料庫、密碼保險箱…）都開在某個專案裡，費用算到那個專案的帳單帳戶上。

新帳號試用金
一筆試用額度，有使用期限，用完或到期就結束
每月免費用量
部分服務每個月有固定免費的量，超過才計費

詳細的金額和期限常常調整，開始前請 AI 查最新說明。綁卡是為了確認身分與之後計費。
