預約流程

  1. 選商品看本週商品，決定想要的種類與數量。
  2. 來電或訊息預約告知取貨日期、時間與姓名。
  3. 等待確認我們會回覆是否額滿，並保留商品。
  4. 到店取貨報姓名後付款取貨，保留當天享用。
