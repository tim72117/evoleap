課程目標頁

課程描述

建議約 64 字
已填入後台
跟著真實開源專案，打造一個用自然語言操作的 AI 助理：讓使用者打字問問題，Agent 自動判讀問題、跑分析、繪製合適的統計圖表，做出一個能上線的整合應用。

哪些人適合這堂課？

已填入後台
這堂課適合： - 具備 JavaScript/TypeScript 基礎、想把 LLM 工具呼叫（tool calling）整合進自己產品的前端或全端工程師 - 想了解 AI Agent 如何「真正動手做事」而不只是聊天機器人的開發者 - 需要在工作中評估或導入 AI Agent 整合方案的技術主管 - 想徹底搞懂工具呼叫（tool calling）的底層原理，學完後能快速為自己的產品打造自然語言驅動介面的學員 這堂課較不適合： - 完全沒有 Web 開發經驗、不熟悉 JavaScript 基礎語法的初學者 - 想學習 LLM 模型訓練或底層原理的學員（本課程專注在應用整合層，不涉及模型訓練）

你可以學到

已填入後台
完成這堂課後，你將能夠： - 把一個操作畫面改造成「打字就能用」的自然語言介面，讓 AI 自動理解使用者的問題、選對工具並執行 - 設計一個 LLM 可呼叫的工具介面，寫出 LLM 能準確理解、正確呼叫的參數 Schema - 最終獨立完成一個涵蓋多種工具類型、並已上線的完整 AI Agent 整合應用（期末專案） - 掌握工具呼叫的共通設計邏輯，這套能力能直接用來快速打造自然語言驅動的介面，不被單一工具綁住

上課前的準備

工具／軟體與背景知識分兩欄填入
待填入後台
(1) 需要準備的工具 / 軟體
- 電腦（Mac / Windows / Linux 皆可）與終端機（Terminal） - Git（版本控制） - Node.js（建議 LTS 版本）與 npm - Docker（用於部署單元的實作練習） - 一個可用的程式碼編輯器（建議 VS Code） - Claude Code（課程採 Vibe Coding 方式實作，會用 AI 輔助寫程式） - onagent 帳號與 API key（課程中會引導註冊）
(2) 需要具備的背景知識
- 熟悉 JavaScript / TypeScript 基本語法與基礎 Web 前端開發（DOM、fetch/WebSocket、npm 套件管理） - 會使用終端機與 Git 進行基本版本控制操作 - 不需要具備機器學習或 LLM 模型訓練相關背景知識
待確認 工具清單裡的「Docker（用於部署單元的實作練習）」與「onagent 帳號與 API key」，是依較早的課程架構寫的。部署單元已不在目前範圍內，這兩項是否保留，請決定後我再改。
