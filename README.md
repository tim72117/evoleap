# onagent 線上課程規劃

把 onagent 開發範例轉製成數位線上課程（Hahow）的所有規劃內容。

## 從這裡開始

打開 `proposal/index.html`（本地網頁，頂端導覽可切換頁面）：

- `proposal/index.html` — 總覽與進度
- `proposal/fields.html` — 提案內容（可一鍵複製貼進 Hahow 後台）
- `proposal/structure.html` — 課程架構（各單元現況）
- `proposal/cover.html` — 封面圖

## 其他

- `materials/cover-designer.html` — 封面設計頁（長形 1000×620、方形 800×800）
- `materials/course-cover.png` — 長形封面圖檔（待重新輸出）
- `materials/showcase-*.png` — 來自 `apps/landing/showcase` 的畫面素材
- `線上課程設計與影音製作-研究報告.md`、`research_notes/` — 課程設計與影片製作研究
- `hahow-課程目標.md` — 提案內容的純文字版本
